# Gestor academico con estructuras de datos propias

Aplicacion Java que modela un curso completo con estudiantes, actividades, entregas, calculos y reportes para dos semestres.

## Estructuras y funcionalidades

* `ListaCompuesta<T>` como lista enlazada generica.
* `Pila<T>` y `Cola<T>` para operaciones LIFO y FIFO.
* Manejo de fracciones para notas y calculos ponderados.
* Carga de datos desde archivos CSV.
* Consultas de actividades vencidas, entregas incompletas, notas repetidas y calculos pendientes.
* Reportes individuales y combinados de los semestres.
