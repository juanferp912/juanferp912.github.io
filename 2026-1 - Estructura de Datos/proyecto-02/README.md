# Agenda de contactos con busqueda por prefijo

Aplicacion Java para administrar una agenda de contactos desde consola, con carga y exportacion de archivos de texto.

## Estructuras y funcionalidades

* Agenda de contactos con insercion y eliminacion.
* Busqueda por prefijo mediante una estructura de arbol de prefijos.
* Heap para priorizar o gestionar contactos segun su frecuencia.
* Ordenamiento por burbuja de los resultados mas consultados.
* Lectura desde `contactos.txt` y exportacion de respaldos.
* Interfaz de consola y clase de interfaz grafica.
