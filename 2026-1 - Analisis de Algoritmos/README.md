## Proyecto 01 - Propagacion de Malware en un Servidor mediante Grafos

Proyecto grupal que modela la propagacion de malware entre dos computadoras como un grafo dirigido y ponderado. Compara Dijkstra y Bellman-Ford para encontrar rutas con mayor probabilidad acumulada.

* **Tecnologias:** Python, NetworkX, Tkinter, Matplotlib, CSV y unittest.
* **Documentacion tecnica:** [Ver detalles del proyecto](./proyecto-01/)
* **Repositorio oficial externo:** [ueesaalg/aalg_act2_2p_ord1_26_grupo3](https://github.com/ueesaalg/aalg_act2_2p_ord1_26_grupo3)
